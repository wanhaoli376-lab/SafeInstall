# Code of Conduct

## Our commitment

We are committed to a respectful, harassment-free community for everyone, regardless of
experience, identity, background, disability, appearance, or viewpoint. Technical disagreement
is welcome; personal attacks, intimidation, discrimination, and unwanted sexual attention are
not.

## Expected behavior

- Be specific, constructive, and patient.
- Critique code and claims rather than people.
- Respect privacy, embargoed vulnerabilities, and responsible disclosure.
- Avoid sharing real secrets, harmful payloads, or personal data in public artifacts.
- Accept maintainer decisions about scope and safety even when you disagree.

## Enforcement

Report conduct concerns privately to the repository owner using the contact method on their
GitHub profile. Maintainers may edit or remove content, warn participants, temporarily restrict
participation, or permanently ban repeated or severe violations. Reports will be handled as
confidentially as practical, with conflicts of interest disclosed and avoided.

This code applies in project spaces and when someone publicly represents the project.
