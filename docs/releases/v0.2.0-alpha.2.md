# SafeInstall v0.2.0-alpha.2

## Prepared release notes — not yet published

These notes describe the next public testing prerelease being prepared on `main`. They do not
mean that a `v0.2.0-alpha.2` Tag or GitHub Release exists. Publish only after the maintainer
checklist, build-only rehearsal, review, and explicit Tag creation are complete.

### Windows x64

The planned Windows asset remains `SafeInstall-Windows-x64.zip`. Local scanning does not require
Python, pip, Git, an account, an OpenAI account, or an OpenAI API key. The binary is not signed, so
Microsoft Defender SmartScreen may show a reputation warning. Do not disable Defender or
SmartScreen to run SafeInstall.

### macOS Apple Silicon (experimental)

The planned `SafeInstall-macOS-arm64-unsigned.zip` asset supports **Apple Silicon (arm64) only**
and does not support Intel Macs. It is not signed with an Apple Developer ID and is not notarized,
so macOS Gatekeeper may display a warning.

The build workflow uses an explicit GitHub-hosted arm64 runner, rejects a non-arm64 main
executable, and validates the generated `Info.plist` against the package version:

- `CFBundleShortVersionString`: `0.2.0`
- `CFBundleVersion`: `2`
- in-app package version: `0.2.0a2`

## Changes prepared for Alpha.2

- Enabled a working private vulnerability-reporting path for SafeInstall security defects.
- Made the macOS architecture explicit in the asset name and user documentation.
- Derived Apple bundle versions from `pyproject.toml` instead of PyInstaller defaults.
- Added build and release validation for arm64 Mach-O architecture and bundle metadata.
- Added repository checks for release documentation and Issue Form label contracts.

## Security boundary

SafeInstall performs static risk analysis. It does not execute scanned code by default, install
target dependencies, import target Python packages, automatically upload local files, enable AI
by default, or provide a malware-free guarantee. The portable builds do not include the OpenAI
SDK; optional AI remains outside the core local-scanning path.

The planned Release must still include exactly four verified assets: the Windows ZIP, the arm64
macOS ZIP, `SHA256SUMS.txt`, and a CycloneDX 1.6 `SBOM.json` whose root version is `0.2.0a2`.
